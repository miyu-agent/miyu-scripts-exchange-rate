# Exchange rate

> <sub>This document was generated by Anthropic's Claude Fable 5.2.</sub>

This is a script package for Miyu. It provides one tool, `exchange_rate`, which converts an amount at the latest exchange rate and can also look up the rate on a past day. The rates come from the following two sources:

- The main source is [Frankfurter](https://frankfurter.dev) (the v2 API, which provides rates published by central banks, covers more than 160 currencies, has historical rates, needs no key and requires no attribution).
- The fallback source is open.er-api.com, the free API of [ExchangeRate-API](https://www.exchangerate-api.com): the tool asks it only when Frankfurter cannot be reached or lacks a currency, and it only provides the latest rates; it requires attribution, so whenever it is used, the output names it as the source.

## Parameters

The tool takes the following parameters:

| Parameter | Description |
|---|---|
| `base` | Required. The currency to convert from: an ISO 4217 code (`USD`) or a common Chinese name (`美元`, `日元`, `港币` and so on) |
| `target` | Required. The currency to convert to; you can give several, separated by commas, for example `日元,欧元,CNY` |
| `amount` | The amount, default 1 |
| `date` | The day whose rate to look up, in the format `YYYY-MM-DD`; when it is left out, the latest rate is used. This only uses Frankfurter, and for weekends and holidays it gives the most recent rate published before that day |
| `format` | `md` (default) or `json` |

## Notes

This section explains caching, the dates and sources in the output, and what the tool covers.

- The tool uses only the Python standard library. Rate tables are cached in `MIYU_CACHE_DIR`: the latest rates are cached for 1 hour; the rates of a past day never change, so they are always taken from the cache.
- Every line of the output states the date of the rate and the source actually used (in `json`, these are the `date` and `source` of each line). Frankfurter's date is the effective date published by each central bank, and it may be one day earlier or later than the local date.
- These are reference rates, not bank rates.
- The tool does not support cryptocurrencies.
