# 汇率查询

> <sub>本文档由 Anthropic 的 Claude Fable 5.2 生成。</sub>

这是 Miyu 的一个脚本软件包，提供一件工具 `exchange_rate`，它按最新的汇率换算金额，也可以查询过去某一天的汇率。汇率来自下面两个数据来源：

- 主数据来源是 [Frankfurter](https://frankfurter.dev)（v2 接口，提供各国央行公布的汇率，覆盖 160 多种货币，有历史汇率，不需要密钥，也不要求署名）。
- 备用的数据来源是 [ExchangeRate-API](https://www.exchangerate-api.com) 的免费接口 open.er-api.com：只有 Frankfurter 连不上或者缺少某种货币时，工具才会查询它，而且它只提供最新汇率；它要求注明来源，所以用到它时，输出里会写明来源。

## 参数

这件工具接受下面这些参数：

| 参数 | 说明 |
|---|---|
| `base` | 必填。要换算的原货币：ISO 4217 代码（`USD`）或者常见的中文名（`美元`、`日元`、`港币`……） |
| `target` | 必填。要换算成的货币，可以写多种，用逗号隔开，例如 `日元,欧元,CNY` |
| `amount` | 金额，默认是 1 |
| `date` | 要查询哪一天的汇率，格式是 `YYYY-MM-DD`；不填写时查询最新的汇率。这一项只使用 Frankfurter，查询周末、假日时给出的是此前最近一次公布的汇率 |
| `format` | `md`（默认）或者 `json` |

## 注意

这一节说明缓存、输出里的日期和来源，以及工具的适用范围。

- 工具只使用 Python 标准库。汇率表缓存在 `MIYU_CACHE_DIR` 里：最新汇率缓存 1 小时；过去某一天的汇率不会再变化，所以一直使用缓存。
- 输出的每一行都写明汇率的日期和实际使用的数据来源（在 `json` 里是每一行的 `date` 和 `source`）。Frankfurter 的日期是各国央行公布的生效日期，可能比本地日期早一天或者晚一天。
- 这些汇率是参考汇率，不是银行牌价。
- 工具不支持加密货币。
